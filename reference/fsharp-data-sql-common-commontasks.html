groupKeyColumn keys index column notation plain

Full Usage: groupKeyColumn keys index column notation plain

Parameters:
    keys : (alias * SqlColumnType) list
    index : int
    column : SqlColumnType
    notation : string
    plain : string

Returns: string

The select-list entry of a group-key column. In a key of several columns, a computed one (a CASE for x.IsSome or x.IsNone) is aliased sqlp_key, with trailing underscores until it differs from the names of the key's plain columns, ignoring case. Results are read by name: left unaliased, two computed keys come back under one name (PostgreSQL and SQL Server do not name them by their text), and a name shared with a plain key column loses one value, so the key tuple cannot be rebuilt. Every other key column keeps `plain`, the provider's usual entry.

keys : (alias * SqlColumnType) list
index : int
column : SqlColumnType
notation : string
plain : string
